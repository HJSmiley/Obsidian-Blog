# 1. Proxmox 설치
하드웨어 세팅은 아버지께서 사무실에 구비해두신 서버 컴퓨터 중 하나를 사용했기에 생략 - 랜카드 꽂고 모니터 연결하고 등등의 ~~귀찮은~~ 과정들도 나중에 직접 해 보고 싶다.

여튼 난 이미지 구워서 os 부팅디스크 만드는 단계에서부터 컴퓨터 세팅을 시작하는 게 처음이기 때문에, Proxmox 공식 웹사이트 + 유튜브 + Gemini 가이드 등등 이것저것 참고해서 세팅했다. 다음은 제미나이가 준 가이드 내용임. 근데 내 컴퓨터에는 이미 우분투가 깔려 있던 상태라 BIOS 진입해서 Priority 조정하는 과정이 추가됐음.

## Proxmox VE 최적화 설치 가이드

Proxmox는 일반적인 프로그램(Type 2)과 달리, 하드웨어 위에 직접 설치되어 자원을 극대화하는 **Type 1(Bare-metal) 하이퍼바이저**입니다. 기존 데비안(Debian) 리눅스 위에 패키지 형태로 올리는 방법도 존재하지만, 네트워크와 스토리지 설정이 꼬이는 딜레마가 발생하기 쉬우므로 **공식 ISO를 통한 클린 설치**가 가장 압도적으로 안정적인 해결책입니다.

### 1. 설치 전 필수 준비 및 확인 사항

|**구분**|**요구 사항 및 확인 내용**|
|---|---|
|**BIOS 설정 (필수)**|CPU 가상화 기술 활성화 (Intel: **VT-x**, AMD: **SVM** 또는 **AMD-V**)|
|**설치 미디어**|8GB 이상의 빈 USB 플래시 드라이브|
|**네트워크 환경**|유선 랜(Ethernet) 연결 필수 (서버 구동용 고정 IP 할당을 위해)|
|**디스크 상태**|설치 대상 디스크 내 모든 데이터 삭제 동의 (깡통 상태 권장)|

---

### 2. 단계별 설치 프로세스

**Step 1: Proxmox 부팅 USB 제작 (다른 PC에서 수행)**

1. Proxmox 공식 홈페이지(proxmox.com)에서 **Proxmox VE ISO Installer**를 다운로드합니다.
    
2. Rufus (윈도우) 또는 BalenaEtcher (Mac/리눅스)를 이용해 다운로드한 ISO 파일을 USB에 굽습니다.
    

**Step 2: 설치 환경 진입**

1. 준비된 깡통 컴퓨터에 USB를 꽂고 부팅 순서를 USB로 맞춰 부팅합니다.
    
2. 검은 화면에 Proxmox 로고가 뜨면 `Install Proxmox VE (Graphical)`를 선택합니다.
    

**Step 3: 시스템 환경 설정 (핵심)**

설치 마법사의 지시에 따라 다음 항목들을 신중하게 기입합니다.

- **Target Harddisk:** Proxmox가 설치될 디스크를 선택합니다.
    
- **Country / Timezone:** South Korea / Asia/Seoul
    
- **Password / Email:** **루트(root) 관리자 비밀번호**를 설정합니다. (절대 분실하면 안 됩니다.)
    
- **Management Network Configuration:**
    
    - `Hostname`: 서버의 이름 (예: `pve.local`)
        
    - `IP Address`: 공유기 대역에 맞는 **고정 IP** 입력 (예: `192.168.0.100`)
        
    - _이 IP 주소가 향후 서버를 관리할 접속 주소가 됩니다._
        

**Step 4: 설치 완료 및 접속**

1. 설치가 완료되면 자동으로 재부팅됩니다. (이때 USB를 제거합니다.)
    
2. 부팅이 완료되면 검은색 CLI 화면에 로그인 프롬프트와 함께 접속 주소(`https://설정한IP:8006`)가 나타납니다.
    
3. **동일한 공유기에 연결된 다른 컴퓨터의 웹 브라우저**에서 해당 주소로 접속합니다. (보안 경고가 뜨면 '고급 - 무시하고 이동'을 선택합니다.)
    
4. ID에 `root`, 비밀번호에 설치 시 설정한 암호를 입력하여 Proxmox 관리자 페이지에 진입합니다.
    

# 2. Proxmox VE 웹 콘솔로 접속해 설정
![[image-20260329-221747.png]]
고정 IP는 192.168.0.100에 연결했고 8006번 포트가 Proxmox VE 웹콘솔의 기본 포트. 여기서 VM도 만들고 이것저것 관리할 수 있다.

![[image-20260329-221803.png]]
처음에 오류 떠서 헉 설치할 때 뭘 잘못했나 아직 언마운팅 중인데 USB드라이버를 너무 빨리 뽑았나? 설레발쳤는데 그냥 유료 구독 안 해서 사용 못하는 기능들 있다고 빨갛게 띄운 거였음. 업데이트>리포지토리 들어가서 enterprise 붙은 항목 다 비활성화하고 새로고침하면 해결된다.

![[image-20260329-222805.png]]
나중에 집에서도 작업할 수 있게 공유기 게이트웨이 들어가서 포트포워딩도 설정해 뒀다. 근데 이러면 보안적으로 문제가 있을 수 있기에(공인IP 알고 있으면 관리자 비밀번호만 알아내면 바로 그 안의 VM들 다 제어 가능) 나중에 조치할 생각.

VM 세팅 다 하고 나면 Proxmox 웹콘솔은 포트포워딩 해제하고, VM들이 있는 내부망으로 연결되는 방화벽을 설치해서 걔를 포트포워딩하는 식으로 조치한 글이 있던데 그걸 참고해서 나머지를 설정해볼 예정이다.

![[image-20260329-221825.png]]
우분투 웹사이트에서 다운받은 iso 파일까지 업로드해주기. 근데 지금 생각해 보니 24 LTS 버전으로 다운받을 걸 그랬음,,, 나중에 다 깔고 나서 또 업그레이드하는 이중의 수고를 들이게 되었다.

# 4. OpenClaw 설치
![[image-20260329-221914.png]]
집에 와서는 그냥 유튜브에서 오픈클로 설치 가이드 검색해서 그거 보고 따라했다. curl로 인스톨하면 필요한 다른 패키지나 도구들(prerequisites)까지 같이 설치해준다길래 그걸로 함.

![[image-20260329-221926.png]]
전부 인스톨 고고

 문제는 여기서 발생. 이거 하고 잠깐 블로그 글 작성하고 오니 세션이 너무 오래 띄워져 있어서 중단되었다. 그래서 다시 curl 명령어를 쳐서 오픈클로 설치를 처음부터 재시작했더니 config가 덮어씌워졌는지 아니면 뭔지 자꾸 gateway 설정에서 오류가 나기 시작함.

여차저차 트러블슈팅 끝에 온보딩 설정을 완료하지 못해서 제대로 판단을 못하는 거였다. 그래서 다시 `openclaw gateway stop` → `openclaw onboard`으로 설정 완료했더니 gateway connected 뜨면서 오픈클로 설치가 완료되었다!
