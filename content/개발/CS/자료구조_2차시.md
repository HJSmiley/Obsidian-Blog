'오버 헤드(overhead)'는 머리 위를 의미하는 영어 단어에서 유래했지만, 주로 어떤 작업을 수행하기 위해 투입되는 직접적인 비용이나 시간, 자원 외에 추가적으로 소요되는 간접적인 자원을 의미합니다. 컴퓨터 시스템에서는 주된 작업 외에 부수적으로 발생하는 시간이나 메모리 사용 등을, 비즈니스에서는 임대료나 전기세 같은 고정 비용을, 통신에서는 정보 전송에 추가되는 신호 등을 오버 헤드라고 합니다. 

- 컴퓨터 시스템 오버 헤드:  
  - 프로그램 실행 시, 특정 코드를 실행하기 위해 추가로 사용되는 시간이나 메모리를 의미합니다.  
  - 함수 호출 시 함수 내용 실행 시간이 아닌, 함수를 호출하는 데 들어가는 비용을 포함합니다.  
  - 사용자나 프로세스에 이점을 제공하지만 특정 작업에 직접 기인하지 않는 공유 기능도 오버 헤드에 해당할 수 있습니다.

## Composite Data Type

시험문제 단골\! – 함정 존재  
A composite data type is a type that stores a collection of individual data components under one variable name.  
It allows the individual data components to be accessed.

structured / unstructured 두 가지로 분류  
structured → 내부에 동일한 데이터 타입을 가지고 있음 ex. Arrays (structured)  
unstructured → ex. Class (unstructured), Struct (**unstructured**)

struct는 c에서 composite data type의 필요성이 나왔기 때문에 사용했음 (c에는 class가 존재하지 X) → oop 개념이 나오면서 c++가 나오고 class가 나오고  
→ struct는 내부 접근 지시자 디폴트가 public으로 되어 있고 class는 private으로 되어 있음  
관용적으로 struct는 멤버 변수들로만 이루어진 변수들의 집합 덩어리  
(여러 데이터 값을 갖는 어떤 새로운 타입을 정의할 때 흔히 구조체를 사용)
