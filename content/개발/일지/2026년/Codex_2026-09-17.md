# 2026\-09\-17 개발일지 — 병합한 개발 환경과 남은 실행 확인

> 일부 수집: 일부 작업 소스, Mac-mini 미수집 또는 확인 불완전.

## 오늘의 흐름

로컬 개발 환경 정리 PR \#773이 main에 병합됐다\. 그러나 병합 뒤 사용자 환경에서 Web BFF 요청이 필수 설정 누락으로 실패했다\. 오늘의 결과는 병합까지이며, 실제 기동 확인은 다음 단계로 남는다\.

Quote 알림 서버는 활성화 시점과 기존 실행 이력의 재생 문제를 고쳐 Ready가 됐다\. 원격 Quote 승인 복구는 커밋 검사에 막혔고, Quote 정책·동의 구현은 로컬 커밋까지 진행했다\. 두 작업 모두 원격 전달과 통합 확인이 남아 있다\.

사용자는 \#726 병합 전까지 후행 스택 작업을 멈추기로 했다\. 밤의 \#921에는 게시물 조회 권한 리뷰가 남아 있어, 낮의 CI 성공을 하루 전체의 완료로 해석하지 않았다\.

## 개발 환경: 병합 뒤 실제 실행에서 남은 설정 문제

진행: 진행 중 · 검증: 일부 확인 · 반영: 병합

### 무엇이 달라졌나

기록상 보고: 개발 프로세스 실행을 pnpm 병렬 실행으로 단순화하고, DB 역할·권한 설정 책임을 local:prepare로 모았다고 보고됐다\. API·Web·App·Worker·Fedify consumer를 실행하는 구성이며, 매번 수행하던 인증·권한 사전 검사를 줄였다\.

### 어디까지 확인했나

마지막 정리에서 OpenSpec strict 132개, 관련 ESLint 8개와 CI 16개 성공을 확인했다\. 이전 로컬 전체 실행에는 Storybook 실패와 재시도가 있었으므로 모든 검사가 한 번에 통과한 것으로 합치지 않았다\.

### 무엇이 달라졌나

자동 병합 시도가 멈춘 뒤 사용자가 직접 병합했다\. GitHub 조회로 18시 1분 main 병합을 확인했다\. 다만 코드가 main에 들어간 사실만으로 사용자 환경의 실행까지 확인된 것은 아니다\.

### 어디까지 확인했나

병합 뒤 로컬 Vault 설정 문제가 보고됐고, 직접 HTTP 확인에서 API는 200 응답을 냈지만 Web BFF는 500과 INTERNAL\_API\_ORIGIN 필수 오류를 반환했다\. 테스트·병합 결과와 실제 실행 결과를 따로 남겨야 하는 지점이다\.

### 무엇이 남았나

기록상 보고: 마지막 안내는 로컬 Vault에 INTERNAL\_API\_ORIGIN을 추가하고 개발 프로세스를 재시작하는 것이었다\. 값을 넣고 Web BFF를 다시 확인한 후속 결과는 당일 기록에 없었다\.

## Quote 알림: 활성화 시점과 이전 실행 이력의 호환성

진행: 진행 중 · 검증: 일부 확인 · 반영: PR 열림

### 무엇을 해결하려 했나

호환 Worker가 준비되기 전에 기능이 자동으로 활성화되면 알림을 놓칠 수 있었다\. 실제 검증에서는 자동 활성화 시점과 기존 Workflow 재생 회귀가 실패했다\.

### 무엇이 달라졌나

자동 활성화를 명시적 활성화로 바꾸고 최초 활성화 시각 T0를 보존했다\. 이전 Local·Remote Workflow 이력은 patched 분기로 유지해 새 동작과 구분했다\.

### 어디까지 확인했나

수정 뒤 기존 이력 재생을 포함한 Workflow 2개, Core service 214개, Worker DB 36개와 API 통합 282개가 통과했고 API 1개는 건너뛰었다\. 13시 50분 당시 CI 16개도 성공했다\. 이 결과가 이후 재적층과 새 리뷰까지 포함하지는 않는다\.

### 무엇이 남았나

기록상 보고 / 추정: PR \#921은 13시 45분 Ready로 전환됐으나 미병합이었다\. 원격 Quote의 승인·철회 시점과 Mention 연계, 운영 활성화·rollback 검증은 남았다\. Ready 전환 뒤 이슈 상태를 In Review로 둘지 In Progress로 되돌릴지도 아직 확정되지 않았다\.
